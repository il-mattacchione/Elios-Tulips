# 🌷 Elio's Tulips
A Minecraft Fabric mod that brings botanical accuracy to vanilla tulips.
Featuring *photonasty* (Open petals during the day, closed petals at night) and *heliotropism* (Stems that lean towards the light).

*Trivia: The name comes from the Greek god of the sun Helios, from which heliotropism was named. Elio is the Italian name for Helios.*
